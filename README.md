# painel-lateral

Mod do Claude Code: painel lateral com abas Overview, Tarefas, Tokens, Log, Arquivos, Notas e Ajustes.

## Instalar

Num terminal com o `claude` aberto:

```
/plugin install painel-lateral --marketplace OWNER/painel-lateral
```

Responde `y` para adicionar o marketplace e escolhe o scope **user**.

## Comandos

- `/painel` abre o painel (`/painel ajuda` para todos os subcomandos)
- `/tema nardo|escuro|claro|auto` muda o tema do Claude
- `/tema cor nardo|grafite|prata|cimento` muda a cor do painel
